# Community code of conduct

Contributors and participants should treat one another respectfully, welcome people with different backgrounds and experience, give constructive feedback on work, and accept correction. Disagreement about evidence and engineering decisions is expected; personal attacks, harassment, discriminatory language, sexualized conduct, threats, and publication of private information are not acceptable.

This applies to repository discussions, issues, reviews, project-managed spaces, and public representation of the project. Maintainers may edit or remove harmful content, warn participants, temporarily restrict participation, or exclude repeated or severe misconduct. Enforcement should consider context, protect affected people, and explain decisions where privacy permits.

Report concerns privately to a repository maintainer using an available private contact channel. If no private contact is listed, request one without disclosing sensitive details publicly. A dedicated conduct contact has not yet been established. Reports will be handled with care; confidentiality and response times cannot be guaranteed before the project establishes a formal maintainer process.
